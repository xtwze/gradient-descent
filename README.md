## ✨ О проекте

Этот проект демонстрирует **классический градиентный спуск** для задачи линейной регрессии. 

Мы обучаем модель предсказывать **прибыль автосервиса (СТО)** в зависимости от количества автомобилей в городе. Проект выполнен в учебных целях и идеально подходит для демонстрации базовых навыков машинного обучения.

### Что реализовано:
- Визуализация исходных данных
- Разделение на train/test
- Реализация функции стоимости (Cost Function)
- Градиентный спуск с нуля (без библиотек)
- Визуализация линии регрессии
- Сохранение обученных параметров
- Прогнозирование на новых данных

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/xtwze/gradient-descent.git
cd gradient-descent
2. Установите зависимости
Bashpip install -r requirements.txt

📁 Структура проекта
textgradient-descent/
├── main.py          # Основной скрипт: обучение + визуализация
├── work.py          # Прогнозирование на новых данных
├── DataSet.txt      # Датасет (97+ примеров)

🧠 Как это работает

warmUpExercise — создание единичной матрицы
plotData — красивая визуализация данных
gradientDescent —核心 алгоритм спуска
computeCost — расчёт функции ошибки
predict — оценка на тестовых данных

Модель обучается за 1500 итераций с learning rate α = 0.01.
